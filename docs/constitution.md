# Constituição do Projeto

1. Use Python 3.14+ e `pytest` para todos os testes.
2. Mantenha o código simples e sem dependências externas desnecessárias.
3. Todas as regras de negócio devem seguir rigorosamente as especificações documentadas em `docs/specs/frete.md`.
4. O framework web padrão para a API e rotas deste projeto é o Flask.
5. Siga o plano de desenvolvimento definido em `tasks.md` para garantir o controle e a qualidade das entregas.
